2. 완성 글 확인

직접 수정 가능

명단·날짜·선택 방식이 변경되었습니다. ‘확인 · 글 만들기’를 다시 눌러주세요.

앱에서 공유창을 지원하지 않으면 복사를 이용하세요. 공유 메뉴는 Chrome에서 다시 시도할 수 있습니다.

휴대폰 공유 메뉴에서 카카오톡을 선택하세요. 카카오톡이 보이지 않으면 복사 후 붙여넣으세요.

아이폰 · 안드로이드 사용 안내

이 주소를 아이폰 Safari 또는 안드로이드 Chrome·삼성 인터넷에서 열어 사용하세요. 카카오톡 안에서 열었을 때 복사나 공유가 안 되면 휴대폰 기본 브라우저에서 다시 열어주세요.

자주 사용하면 브라우저 메뉴의 홈 화면 추가 기능으로 바로가기를 만들 수 있습니다. 기본 명단은 브라우저별로 저장되므로 같은 브라우저를 계속 사용하세요.
